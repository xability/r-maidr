# The smallest canvas a candlestick chart is drawn on, in inches

quantmod's
[`chartSeries()`](https://r.maidr.ai/reference/base-r-wrappers.md) lays
out its title, the bracketed date range on its right and its two-line
month and year labels for a page this wide and no narrower (quantmod
issue \#129); maidr's ggplot2 candlestick is held to the same so the two
agree.

## Usage

``` r
MAIDR_CANDLESTICK_SIZE
```
