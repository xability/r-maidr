# Whether an indicator call is quantmod's volume panel, `addVo()`

Whether an indicator call is quantmod's volume panel, `addVo()`

## Usage

``` r
is_chartseries_volume_ta(calls)
```

## Arguments

- calls:

  Indicator calls from
  [`chartseries_ta_calls()`](https://r.maidr.ai/reference/chartseries_ta_calls.md)

## Value

A logical vector, `FALSE` for `NA`
