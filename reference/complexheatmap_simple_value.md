# The values of a simple annotation, if it is one

The values of a simple annotation, if it is one

## Usage

``` r
complexheatmap_simple_value(single, n)
```

## Arguments

- single:

  A `SingleAnnotation`

- n:

  The number of matrix columns or rows it annotates

## Value

Its vector of values, one per column or row, or NULL when it is not an
`anno_simple()` of a vector of that length with a colour mapping
