# The theme lattice starts a device of the current kind with

What
[`trellis.device()`](https://rdrr.io/pkg/lattice/man/trellis.device.html)
sets for a kind of device lattice has not drawn on yet:
[`standard.theme()`](https://rdrr.io/pkg/lattice/man/standard.theme.html),
in colour except on
[`postscript()`](https://rdrr.io/r/grDevices/postscript.html), with the
`default.theme` lattice option – a list, a function, or a function's
name – over it.

## Usage

``` r
lattice_starting_theme()
```

## Value

A lattice theme.
