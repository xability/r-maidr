# What a pheatmap layer's title says of values that are not exact

By where the values were read from; see
[PheatmapHeatmapLayerProcessor](https://r.maidr.ai/reference/PheatmapHeatmapLayerProcessor.md).
A matrix kept by
[`pheatmap()`](https://r.maidr.ai/reference/pheatmap.md) is exact and
says nothing.

## Usage

``` r
PHEATMAP_VALUE_NOTES
```
