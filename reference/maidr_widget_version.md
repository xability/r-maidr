# The maidr.js version a widget loads

The maidr.js version a widget loads

## Usage

``` r
maidr_widget_version(use_cdn)
```

## Arguments

- use_cdn:

  Logical, as in
  [`maidr_htmlwidget()`](https://r.maidr.ai/reference/maidr_htmlwidget.md).

## Value

The bundled `MAIDR_VERSION`, or the version CDN documents load, which
may be `"latest"`
