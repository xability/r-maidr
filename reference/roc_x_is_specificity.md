# Whether a ROC layer's x is specificity, to be announced as `1 - x`

Whether a ROC layer's x is specificity, to be announced as `1 - x`

## Usage

``` r
roc_x_is_specificity(layer, plot_object)
```

## Arguments

- layer:

  A ggplot2 layer

- plot_object:

  The plot the layer belongs to

## Value

TRUE only for a detected layer whose x is specificity itself
