# Whether a matrix kept with a pheatmap is the one its cells were drawn from

Whether a matrix kept with a pheatmap is the one its cells were drawn
from

## Usage

``` r
pheatmap_matrix_fits(values, fill)
```

## Arguments

- values:

  The `"maidr_matrix"` attribute, or NULL

- fill:

  The cells' fill colours

## Value

TRUE when it has the cells' shape and names
