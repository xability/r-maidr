# The title the chart's key draws, when it draws one

`auto.key = list(title = "Cylinders")` and `key = list(title = ...)`
give the key a title, written above its entries; `auto.key = TRUE` draws
none.

## Usage

``` r
lattice_key_title(plot)
```

## Arguments

- plot:

  A trellis object

## Value

A string, or `NULL`.
