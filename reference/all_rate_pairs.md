# Whether every point of every series is a pair of fractions of one

Whether every point of every series is a pair of fractions of one

## Usage

``` r
all_rate_pairs(data)
```

## Arguments

- data:

  A list of series, each a list of points with `x` and `y`

## Value

TRUE when there is at least one point and every `x` and `y` is a number
from 0 to 1
