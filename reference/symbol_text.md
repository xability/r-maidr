# A text, when a symbol replayed under it would carry it

NA for an empty text; for one longer than R allows a symbol's name
(10,000 bytes); and for `...` and `..1`, which R reads as the dots of
the frame they are evaluated in.

## Usage

``` r
symbol_text(text)
```

## Arguments

- text:

  A string, or NA

## Value

`text`, or NA
