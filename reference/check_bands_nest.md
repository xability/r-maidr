# Check that a fan's bands nest, each strictly inside the next wider one

Check that a fan's bands nest, each strictly inside the next wider one

## Usage

``` r
check_bands_nest(bands, fail)
```

## Arguments

- bands:

  Checked bands, from
  [`validate_percentile_band()`](https://r.maidr.ai/reference/validate_percentile_band.md)

- fail:

  Raises an error located on the fan

## Value

NULL, invisibly
