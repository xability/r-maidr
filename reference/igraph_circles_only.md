# Whether `plot.igraph()` draws every vertex as a circle

Whether `plot.igraph()` draws every vertex as a circle

## Usage

``` r
igraph_circles_only(graph, args)
```

## Arguments

- graph:

  The igraph object

- args:

  The recorded call's arguments

## Value

TRUE when the shape asked for, the graph's own or igraph's default, is a
circle for every vertex
