# [`finish_svg()`](https://r.maidr.ai/reference/finish_svg.md) with xml2

[`finish_svg()`](https://r.maidr.ai/reference/finish_svg.md) with xml2

## Usage

``` r
finish_svg_xml2(svg_content, maidr_data, candlestick = FALSE)
```

## Arguments

- svg_content:

  Character vector of SVG lines, as exported

- maidr_data:

  The maidr-data structure

- candlestick:

  Whether the chart has a candlestick layer

## Value

Character vector of SVG lines
