# What each slice of a split side is called

What each slice of a split side is called

## Usage

``` r
complexheatmap_slice_titles(heatmap, side, count)
```

## Arguments

- heatmap:

  The drawn `Heatmap`

- side:

  `"row"` or `"column"`

- count:

  The number of slices

## Value

The slices' titles, in drawn order, when each has one; else their
numbers
