# The text an argument of a recorded call was written as

The text an argument of a recorded call was written as

## Usage

``` r
written_arg(plot_call, formal)
```

## Arguments

- plot_call:

  A recorded call

- formal:

  The formal the argument was matched to

## Value

A string, or NULL when the call kept no text for it: see
[`written_arg_text()`](https://r.maidr.ai/reference/written_arg_text.md)
