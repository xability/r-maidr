# Which MAIDR adapter reads a widget

Which MAIDR adapter reads a widget

## Usage

``` r
maidr_htmlwidget_adapter(widget)
```

## Arguments

- widget:

  The object passed to
  [`maidr_htmlwidget()`](https://r.maidr.ai/reference/maidr_htmlwidget.md).

## Value

`"plotly"`, `"highcharts"` or `"echarts"`.
