# One string from a flat list of selectors, or the input untouched

One string from a flat list of selectors, or the input untouched

## Usage

``` r
join_selector_list(selectors)
```

## Arguments

- selectors:

  A layer's `selectors` entry

## Value

A single string when `selectors` is a flat, unnamed collection of
non-empty strings; otherwise `selectors` as given
