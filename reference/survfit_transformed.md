# Whether `plot()` of a `survfit` object draws something other than the survival estimate: a `fun` or `cumhaz` transform, or `conf.times` bars

Whether [`plot()`](https://r.maidr.ai/reference/base-r-wrappers.md) of a
`survfit` object draws something other than the survival estimate: a
`fun` or `cumhaz` transform, or `conf.times` bars

## Usage

``` r
survfit_transformed(args)
```

## Arguments

- args:

  The recorded arguments of the
  [`plot()`](https://r.maidr.ai/reference/base-r-wrappers.md) call

## Value

TRUE or FALSE
