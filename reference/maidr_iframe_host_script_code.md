# The listener [`maidr_iframe_host_script()`](https://r.maidr.ai/reference/maidr_iframe_host_script.md) registers, as JavaScript

The same code without its `<script>` element, for a page that runs it
itself, as the webR path does with `new Function()`.

## Usage

``` r
maidr_iframe_host_script_code()
```

## Value

Character string of JavaScript
