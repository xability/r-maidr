# A fan's bands as a list, one entry per band

A fan's bands as a list, one entry per band

## Usage

``` r
percentile_band_rows(bands, fail)
```

## Arguments

- bands:

  A data frame with `series`, `lower` and `upper` columns, or a list of
  lists

- fail:

  Raises an error located on the fan

## Value

A non-empty list
