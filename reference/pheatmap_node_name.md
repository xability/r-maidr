# The grob name of the mark at one node of a pheatmap dendrogram

The mark is exported as the SVG element `#<name>.1.1`.

## Usage

``` r
pheatmap_node_name(side, k)
```

## Arguments

- side:

  `"row"` or `"col"`

- k:

  The node's position in the layer's node order

## Value

A string, `"maidr-pheatmap-row-node-3"`
