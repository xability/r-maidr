# Whether an axis is titled with one word, ignoring case and surrounding space

Whether an axis is titled with one word, ignoring case and surrounding
space

## Usage

``` r
axis_titled(axes, axis, word)
```

## Arguments

- axes:

  A canonical axes list

- axis:

  `"x"` or `"y"`

- word:

  The title, lower case

## Value

TRUE when the axis carries that title
