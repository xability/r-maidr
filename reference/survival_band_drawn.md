# Whether a Kaplan-Meier layer draws its confidence band

Whether a Kaplan-Meier layer draws its confidence band

## Usage

``` r
survival_band_drawn(layer)
```

## Arguments

- layer:

  A [`maidr_survival()`](https://r.maidr.ai/reference/maidr_survival.md)
  layer, or one a survminer figure was redrawn as

## Value

TRUE or FALSE
