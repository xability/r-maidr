# Which of an axis's tick labels R draws

Called with the labels' viewports pushed on the current device; see
[`thin_axis_labels()`](https://r.maidr.ai/reference/thin_axis_labels.md).

## Usage

``` r
axis_labels_kept(labels, horizontal)
```

## Arguments

- labels:

  An echoed axis-label text grob

- horizontal:

  Whether the axis runs across the page (sides 1 and 3)

## Value

A logical vector, one value per label
